## Description

Definir todos los textos del sitio (copy) y los metadatos de SEO local. Esta tarea puede ejecutarse en paralelo con #001. El output de esta tarea alimenta directamente #003 (implementación de SEO en código).

El sitio apunta a búsquedas locales en Las Breñas y Chaco. Los textos deben ser concisos, confiables, y en español argentino. Ver `docs/content/CONTENT_STRATEGY.md` para brand voice y keywords objetivo.

## Acceptance Criteria

- [ ] Title tag definido (incluye keywords "celulares Las Breñas" o similar, ≤ 60 chars)
- [ ] Meta description definida (≤ 160 chars, incluye keyword principal y CTA implícito)
- [ ] H1 del sitio definido
- [ ] Texto del hero (tagline / sub-headline) definido
- [ ] Texto del botón CTA de WhatsApp definido
- [ ] Alt text para imágenes principales definido
- [ ] Mensaje pre-escrito de WhatsApp definido (ej: "Hola, vi tu sitio web y quiero consultar sobre...")
- [ ] `docs/content/CONTENT_STRATEGY.md` actualizado con el copy final en la sección "Page Copy Library"

## Technical Notes

- Verificar volumen real de keywords con Google Search Console o Google Keyword Planner antes de definir title tag
- El número de WhatsApp y la dirección exacta están pendientes (ver open questions en PRD.md) — usar placeholders si no están disponibles
- Consultar `docs/content/CONTENT_STRATEGY.md` para brand voice y forbidden phrases
